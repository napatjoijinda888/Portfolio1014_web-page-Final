# My Project

นี่คือโครงสร้างโฟลเดอร์เริ่มต้นสำหรับการพัฒนาเว็บ รองรับการทำงานทั้งบน Windows และ macOS

## โครงสร้างโฟลเดอร์
- `.vscode/` - ตั้งค่าโปรแกรมซ่อนไฟล์ขยะระบบ
- `assets/` - เก็บไฟล์สถิติต่างๆ เช่น รูปภาพ CSS และ JavaScript
- `src/` - สำหรับเก็บไฟล์ซอร์สโค้ดเพิ่มเติม
- `index.html` - ไฟล์หน้าแรกของโปรเจกต์
